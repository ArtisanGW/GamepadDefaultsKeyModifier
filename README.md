# Gamepad Defaults Key Modifier

Choose what the controller's top face button (Y on Xbox) does when you have no
target:

- **Off** keeps the game's default behavior.
- **World map** toggles the world map.
- **Bags** opens or closes all bags.

When a target exists, the button keeps its existing bound action. Configure the
fallback in **Options > AddOns > Gamepad Defaults Key Modifier**.
