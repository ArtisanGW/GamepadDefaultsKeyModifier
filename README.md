# Gamepad Defaults Key Modifier

On the controller UI, the top face button (Y on Xbox) opens your target's menu,
and does nothing when you have no target. This addon gives it something to do
then:

- **Off** keeps the game's own behavior (the default).
- **Quests & Map** opens or closes the quest log and map.
- **Bags** opens or closes your bags.

Y stays the game's:

- with a target (opens its menu)
- with a window open
- holding LT or RT, or in a vehicle: the skill on that bar's Y
- in combat: the game doesn't let addons follow LT and RT in a fight, so the
  skills under them always come first

With no target, on the HUD's top bar, Y is bound to the game's own key binding
for the action (Toggle Quest Log, Open All Bags), so the window opens as the
game's own and closes without an "Interface action failed".
Settings in **Options > AddOns > Gamepad Defaults Key Modifier**, or `/gpdk`.
